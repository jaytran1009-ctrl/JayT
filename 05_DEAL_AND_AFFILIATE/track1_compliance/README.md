# Track 1 Scoped Activation Pack

This pack is a compliance design package, not a commercial activation.

`#JayTAffiliate` is reserved disclosure copy. It must not appear on public cards until the named provider has supplied written authorization, the exact destination and parameter schema are approved, and a separate runtime review permits activation.

The current router is deliberately non-dispatching. It has no destination URL, no tracking parameters, and cannot redirect. A sandbox build must retain those constraints until the provider-authority gate is satisfied.
