Tableau สำหรับนักศึกษา

เริ่มต้นใช้ Tableau เพื่อสร้างทักษะด้านข้อมูล ยกระดับอาชีพของคุณ และเชื่อมต่อกับชขุมชน

ติดตั้ง Tableau ฟรี
เริ่มต้นเส้นทาง Tableau สำหรับนักศึกษา

ในโลกของ AI และเทคโนโลยีที่มีการเปลี่ยนแปลงอยู่ตลอด เราทราบดีว่าการเรียนรู้เครื่องมือใหม่อาจเป็นเรื่องที่น่าเหนื่อยหน่าย ทำตามคู่มือที่แนะนำนี้เพื่อเริ่มต้นสร้างทักษะ Tableau อย่างรวดเร็วและเรียนรู้เกี่ยวกับชุมชน

1. ดาวน์โหลด Tableau ฟรี

ดาวน์โหลดซอฟต์แวร์ฟรีด้วย Tableau Desktop: Public Edition

2. สร้างโปรไฟล์ของคุณ

สร้างโปรไฟล์ของคุณบน Tableau Public และสมัครใช้บริการ Viz of the Day เพื่อหาแรงบันดาลใจจากภาพข้อมูลที่ชุมชนสร้างขึ้น

3. เรียนรู้เกี่ยวกับ Tableau

สำรวจคลังวิดีโอการฝึกอบรมของเราตั้งแต่ผู้ใช้ระดับเริ่มต้นไปจนถึงขั้นสูง และเข้าชม ช่อง Youtube

4. ทำความรู้จัก DataFam

เรียนรู้แบบพบปะหน้าหรือทางออนไลน์ เชื่อมต่อกับผู้นำในอุตสาหกรรม และค้นหาแรงบันดาลใจรวมถึงชุมชนใน กลุ่มผู้ใช้ Tableau อย่าง Tableau Newbie, LGBTQ+ (Data Pride), Data + Diversity และ Data + Women

5. ทดสอบทักษะด้านข้อมูลของคุณ

พร้อมยกระดับทักษะด้านการแสดงภาพข้อมูลของคุณขึ้นไปอีกขั้นหรือยัง เข้าร่วมการแข่งขันเฉพาะสำหรับนักศึกษาช่วงปลายปี Iron Viz: Student Edition เพื่อลุ้นรางวัลเดินทางเข้าร่วม Tableau Conference ฟรี

6. แนะนำแนวทางแก่นักศึกษาคนอื่นๆ

พร้อมช่วยสนับสนุนนักศึกษาหัวข้อมูลรุ่นใหม่แล้วหรือยัง เราจะเปิดรับสมัคร Academic Ambassadors ระหว่างเดือนกรกฎาคมและเรียนรู้เพิ่มเติมเกี่ยวกับวิธีตอบแทน ชุมชน Tableau

ฉันเคยขอใบอนุญาตแล้ว Tableau Desktop Public Edition (TDPE) นี้คืออะไร

โปรแกรม Tableau สำหรับนักศึกษาได้เปลี่ยนมาให้บริการซอฟต์แวร์ฟรีผ่าน Tableau Desktop Public Edition แม้ว่าผลิตภัณฑ์จะคล้ายกันในด้านความสามารถในการแสดงภาพข้อมูล แต่กระบวนการรับใบอนุญาตฟรีในตอนนี้จะง่ายขึ้นกว่าเดิม ตอนนี้ ผู้เรียนที่อยู่นอกห้องเรียนแบบเดิม เช่น ผู้เรียนนอกเวลา และผู้ฝึกงาน สามารถเข้าถึงซอฟต์แวร์ได้แล้ว

เพียงคลิกปุ่ม “ดาวน์โหลด Tableau ฟรี” ทางด้านบนของหน้าเพื่อเริ่มต้นอย่างรวดเร็ว

ชั้นเรียนของฉันมี Tableau Cloud ฉันจะสามารถเผยแพร่ผลงานของฉันบน Tableau Cloud โดยใช้ Tableau Desktop Public Edition ได้หรือไม่
