Tableau 学生向けプログラム

Tableau を使い始めて、データスキルの習得やキャリアアップに役立てるとともに Tableau コミュニティと交流しましょう

Tableau を無料で入手
Tableau 学生向けプログラムに参加しましょう

絶え間なく変化し続ける AI とテクノロジーの世界では、新しいツールの習得が追いつかないように感じられることもあります。この推奨ガイドを利用して Tableau スキルの習得をさっそく始めましょう。Tableau コミュニティについても学べます。

1. Tableau を無料でダウンロードする

無料ソフトウェアの Tableau Desktop Public Edition をダウンロードします。

2. プロフィールを作成する

Tableau Public のプロフィールを作成します。また、Tableau コミュニティで生み出されたビジュアライゼーションからアイデアを得るために、今日の Viz をサブスクライブしましょう。

3. Tableau を学ぶ

初心者からベテランユーザーの方まで支援するトレーニングビデオのライブラリを活用しましょう。また、Tableau の YouTube チャンネル (英語) もご覧ください。

4. DataFam について知る

Tableau ユーザーグループは、対面やオンラインでの学習、業界リーダーとの交流、アイデアの発見、コミュニティへの参加ができる場です。Tableau Newbies (Tableau 初心者)、LGBTQ+ (Data Pride) (データプライド)、Data + Diversity (データとダイバーシティ)、Data + Women (データと女性) などさまざまなユーザーグループがあります。

5. データスキルを試す

ビジュアライゼーションのスキルをレベルアップしましょう。年末に開催される、学生を対象にしたコンテスト Iron Viz: Student Edition にチャレンジしてみませんか。受賞者の方は Tableau Conference に無料でご招待します。

6. 他の学生を支援する

データを学ぶ次世代の学生をサポートしませんか。6 月に受け付けられるアカデミックアンバサダーへのご応募をお待ちしています。また、Tableau コミュニティに貢献する方法についてもご覧ください。

以前はライセンスを申請する形式でした。この Tableau Desktop Public Edition (TDPE) とは何ですか?

Tableau 学生向けプログラムでは、提供する無料ソフトウェアが Tableau Desktop Public Edition に変更されました。この製品は、Tableau Desktop と同様のビジュアライゼーション機能を備えています。一方で、無料ライセンスを取得するプロセスは遙かに簡単になりました。これにより、科目等履修生や実習生など、通常の授業の外で学ぶ方々も Tableau を利用することができます。
