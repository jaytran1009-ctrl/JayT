# W4 Field Ops Launch Pack

## Coordinator checklist

1. Assign an anonymous session code from the register; do not create a participant roster.
2. Read the consent script verbatim and record only yes/no.
3. Test the live W3 calculator, KTX stack simulation, Spotify Student note, and DanaBus procedure using the moderator protocol.
4. Enter only the allowed anonymous outcomes. A privacy issue stops the session and is escalated without retaining the sensitive content.

## Recruitment boundary

This pack does not send invitations, contact students or employers, schedule a venue, make payments, or claim a completed session. Those actions require an authorized human field coordinator and voluntary participant consent.

## Synthesis rule

After all valid sessions, group anonymous findings by task and segment. Escalate misleading pricing interpretation, confusion between a simulation and a redeemable voucher, or any privacy concern before changing public functionality.
